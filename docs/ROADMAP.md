모델·backend 한 조합을 실제 제품 과제로 검증한 뒤 추가 엔진과 최적화를 같은 수락시험에 넣는다. Seed의 과거 한 호스트 성능 개선을 새 하드웨어의 기본 profile로 일반화하지 않는다.

성공 설명의 정확성, 대상·권한 유효성, 중복 효과 방지, UNKNOWN 보존, 사용자 중단·삭제 반영은 지정 반례에서 모두 통과해야 한다. 작업 성공률·지연·CPU·메모리·개입 횟수의 목표는 시험 과제·하드웨어를 고정한 뒤 실행 전에 정한다.

첫 통합판의 성공은 해당 Linux-hosted 수락 범위이며 심핵·고권한·독자 native·다중 실기기 전체 완료로 승격하지 않는다.
